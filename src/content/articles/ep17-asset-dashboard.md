我算了將近四年的投資報酬率，一直是錯的。

2024 年底，我把所有帳戶的交易紀錄整理出來，用正確的算法重新算了一次，才發現——我一直在看的那個數字，不是我的策略表現，是我帳戶餘額的變化率。兩件事差了將近四個百分點。

我的 Excel 報酬率欄位算的是「帳戶市值相對於總投入的比率」。這個算法有一個根本問題：我每個月都在投入新資金，這些新資金剛進來的時候根本沒有時間增值，但它們的存在讓帳戶市值的總量增加了，讓報酬率看起來比實際的更好看。我以為自己的策略表現不錯，但我根本沒辦法知道——因為我從來沒有把新投入的錢和策略本身的增值分開計算過。

算出來之後，我做了一個決定：用 Excel 管理投資，這件事到此為止。

## TWR 是什麼？為什麼券商不提供這個數字

正確的算法叫做時間加權報酬率，英文 Time Weighted Return，縮寫 TWR。它把每一筆現金流入的時間點當作切分點，每一段分別算報酬，最後把各段的報酬連乘起來。這樣算出來的，才是「不管我投了多少、什麼時候投入，投資策略本身讓每一塊錢增長了多少效率」。

用數字說清楚：

假設一月底你有一百萬，到三月底帳戶值一百一十萬，這段報酬是 10%。三月底你追加二十萬，帳戶變成一百三十萬，到六月底帳戶值一百五十萬。

一般算法：一百五十萬 − 一百二十萬（總投入），除以一百二十萬，得出 25%。但這個 25% 包含了你追加的二十萬的貢獻。

TWR 算法：三月底到六月底這段，一百三十萬變一百五十萬，報酬是 15.4%。然後把兩段連乘：1.10 × 1.154，TWR 約 27%。這個 27% 才是策略的效率，跟你中途追加了多少錢無關。

**大部分券商不提供這個數字**，因為算它需要完整的交易紀錄和時間序列。多數券商的帳戶績效頁面提供的是「持有報酬率」，在你每個月固定投入的情況下，這個數字天然偏高——它把「每次投入的時機運氣」和「策略本身的效率」混在一起，無法分開。你看到的那個報酬率，有一部分是你恰好在某些時間點投入帶來的，不全是策略的功勞。

## 為什麼 Excel 最後撐不住

以示範帳戶小明為例：台幣帳戶持有 0050 和 00631L，海外帳戶持有 VOO、QQQ、VEA、VWO、IAU、IBIT 和 SGOV，加上台幣和美元的現金部位。兩種帳戶，十個部位，幣別不同，平台不同。

用 Excel 管理這些，核心問題不是功能不夠，是每次想知道今天的總資產是多少，都要打開兩個平台手動抄數字、自己換匯加總。再平衡的計算更麻煩：每個部位都有目標比例，要算偏離多少、換算成幾股，台幣以張計、美股以整股計，一不小心就算錯。

工具的維護成本越高，查看頻率就越低。這份 Excel 從每週看一次，慢慢變成每個月才開一次，再平衡的時機點一再被拖延。

最後一根稻草是報酬率。我維護了幾年，那個最重要的數字，一直是錯的。

## 資料隱私：財務數據不應該上雲端

說功能之前，先說最重要的一件事：資料存在哪裡。

Asset Dashboard 把所有資產數據存在你自己電腦上，加上一個你指定的本機資料夾，每天存一份 JSON 快照。數據完全在你的機器上，不傳到任何伺服器，不上雲端，也不經過我的任何系統。

這樣設計的原因是：財務數據比很多人想的更敏感。你的資產規模、持倉比例、每筆交易的時間——這些資訊放在別人的伺服器上，就算是免費服務，也有代價。很多財務工具把「雲端同步」當賣點，但雲端同步意味著你的完整資產快照存在別人的伺服器上，資料一旦外洩，你的資產規模和持倉細節就是公開的。本機儲存讓你的財務隱私掌握在自己手裡。

代價是：換電腦要手動遷移資料，手機上沒辦法直接存取桌面版。如果跨裝置對你比隱私重要，這個工具可能不適合你。但至少你在用之前知道這個取捨在哪裡。

## 打開就看到全局：頂部四個數字

打開 Asset Dashboard，最頂部固定顯示四張統計卡，不管切到哪個功能分頁，它們始終都在。

左邊兩張是今天的總資產：台幣金額和美元金額，按當天匯率自動換算，每次更新報價就自動重算。

右邊兩張跟退休目標掛鉤。目標進度那張顯示現在的資產是目標金額的幾個百分比，下面有一條進度條，還有一行小字告訴你按目前資產規模，距離目標年份還需要達到多少年化報酬率才夠——超過 15% 變紅色，表示達成難度很高；8% 到 15% 是橘色，要留意；8% 以下是綠色，計畫可行。最右邊那張顯示距離目標還差多少，以及還剩幾年。

這四個數字讓你每次打開儀表板第一眼就知道：我現在在哪裡、還差多遠、難度合不合理，不需要切換分頁就能對照全局。

## 功能一：資產分布——現在的全貌

第一個功能分頁是資產分布，顯示今天的即時配置比例。

左半邊是五桶圓餅圖：核心桶、攻擊桶、全球分散桶、另類資產桶、現金防禦桶，五個顏色。這個圖可以點入——點擊任意一個桶，會展開那個桶內每支標的的占比，讓你看到桶內結構有沒有照設計走。

右半邊是目標 vs 實際的水平長條圖，每個桶用灰色代表目標、彩色代表實際，一眼比出五個桶的現實和目標的差距。

如果任何一個桶和目標差了超過五個百分點，頁面頂部會出現偏離警示橫幅，告訴你哪個桶偏了多少，並有一個按鈕直接帶你去再平衡分析分頁。這個觸發條件對應的是偏離型再平衡邏輯——偏離超過五個百分點就要考慮調整了。（詳見 [EP05 再平衡的藝術](/articles/ep05-rebalancing)）

你不需要每次打開都主動去檢查每個桶有沒有偏，警示系統會在條件觸發時出現，讓你在需要行動時主動提醒你，而不是靠焦慮驅動決策。

## 功能二：績效分析——真正的 TWR

績效分析分頁是整個工具最初的核心動機——就是前言裡說的，算了將近四年的報酬率是錯的，這個問題。

最上方顯示四個 TWR 數字：年化報酬率、累計報酬率、今年到現在的 YTD、以及近一年滾動報酬。這四個數字都是 TWR 算法，不是帳戶餘額變化率。

下方月度長條圖顯示每個月的 TWR 表現：哪幾個月特別好、哪幾個月特別差，市場事件或操作決定帶來的影響，都可以在這張圖上追溯。年度長條圖讓你看每一年的整體表現，圖上有一條目標基準線，對應你在退休規劃分頁設定的目標年化報酬率。

月度長條圖可以做回溯診斷：某個月 TWR 特別差，但市場整體沒有大跌，可能是那個月你做了什麼決定帶來的。某個月市場大跌，但你的 TWR 只跌了一半，表示你的分散配置在那個事件中發揮了效果。這些判斷過去要靠感覺，TWR 讓你有數字可以回溯。

**注意**：在你開始使用的第一年，TWR 數字會比較不穩定，因為樣本期間太短。用了一年以上之後，數字才比較有參考意義。這不是工具的問題，而是 TWR 的特性——它反映的是你的真實歷史，不是估算或模擬。

## 功能三：資產走勢——每天一個快照

資產走勢分頁顯示你的總資產從開始記錄以來的歷史折線圖。工具每天打開時，自動儲存今日快照。每天一個快照，日積月累形成這條走勢線。

這條線讓你直觀感受一件事：市場下跌時，帳面總資產確實會短暫向下，但每個月的定投會持續把它往上推。時間夠長，這條線就是一份你紀律的視覺記錄。

市場大跌的時候，這個組合特別有用：帳面資產往下走，你打開儀表板，走勢線確實往下，但 TWR 顯示今年的報酬仍在合理範圍，再平衡分析顯示偏離還在可接受區間——三個分頁一起說：帳面在跌，但策略沒有問題。這比單獨看帳戶餘額的感受要冷靜得多，因為你看到的是三個獨立的數字在同時說同一件事。

## 功能四：退休規劃——把目標畫成三條線

退休規劃分頁是和長期目標連結最直接的功能。

畫面上有三條線。第一條是你過去的實際資產走勢。第二條是從今天往後的預測軌跡，按你設定的每月投入金額和目標年化報酬率延伸出去。第三條是一條水平線，代表你的退休目標金額。

你輸入三個參數：退休目標金額、目標年份、每月計畫投入金額。工具計算出達成目標需要的年化報酬率，畫出這三條線。你可以直接看到：預測軌跡在目標年份之前還是之後穿越水平線。

**最實用的地方是做壓力測試**。把目標年份提前兩年，看所需年化報酬率跳到多少；把每月投入減少一萬，看交叉點往後移多遠。這些假設不需要另外計算，直接改參數，圖立刻更新。讓你知道每個決策的代價，做出決定時更有底氣。

這三條線的邏輯，和 EP15 講的退休目標計算是一套——[EP15 算出那個目標金額](/articles/ep15-retirement-number)，你在這個分頁輸入進去，儀表板幫你追蹤還差多遠。

## 功能五：再平衡分析——下一步該做什麼

再平衡分析分頁分兩塊。

上方是**新資金分配助手**。你輸入這個月要投入多少錢，比如五萬台幣，助手自動算出每個部位應該買多少，優先補充目前配置比例偏離最多的桶。買幾股 VOO、買幾股 0050、買幾股 QQQ——拿到答案，直接對應各自帳戶的下單單位，不需要自己換算。

下方是**各部位缺口表**：每一行是一個部位，欄位包括目前比例、目標比例、差距百分點，以及需要買入或賣出多少。台幣標的顯示張數，美股顯示整股，拿到表就能直接照著下單。可以切換三種視角：全部換算成台幣、只看台幣帳戶、只看美金帳戶。

**實用的執行順序**：先用新資金分配助手把這個月投入分好，看分完之後各桶的偏離是否縮到五個百分點以內。如果可以，這個月只靠新資金調整，不賣任何部位，不承受資本利得稅的問題。如果新資金分完仍有超過五個百分點偏離的桶，才考慮賣出超配部位。

## 功能六和七：持倉明細與交易紀錄

持倉明細分頁是最完整的部位清單，顯示每個標的的持股數量、平均成本、今日現值，以及損益金額和損益百分比。主要是核帳用的：確認每個部位的成本基礎有沒有記錯、今日現值和你自己看到的帳戶數字有沒有對上。損益數字本身的每天波動不需要太在意——它的主要用途不是讓你追蹤帳面盈虧，而是讓你確認成本記錄是否正確。

交易紀錄是 TWR 計算的基礎。要算出正確的 TWR，每一筆現金流入都必須在正確的日期記入，工具才能準確切分計算區間。

**幾個容易漏掉的記錄**：
- 配息要記為「現金入」。0050 和 VOO 定期配息，這些配息如果直接留在帳戶而沒有記，帳戶市值會超出你記錄的成本基礎，TWR 計算會出現誤差。
- 每個月的定期投入要記為「現金入」，工具才知道哪段帳戶成長是新資金帶來的，哪段是策略本身增值的。少記了現金入，TWR 會算得虛高。

## 如何開始使用

工具的源代碼和安裝檔都放在 GitHub（連結在 YouTube 說明欄）。它是 Tauri 桌面應用程式，Windows 使用者直接下載安裝檔，安裝後點開就能用，不需要任何技術背景。完全免費，沒有付費版本。

**第一次設定的流程大概是這樣**：先建立股票帳戶和現金帳戶，接著把歷史買入交易一筆筆記進去，然後設定各部位的目標比例，以及退休目標的三個參數。設定完更新一次報價，所有分頁就有數據了。

**不需要追溯到幾年前每一筆**。可以選一個時間點作為起點，比如今年一月，先把當時的持股記為建立部位的初始交易，再往後記每一筆實際買賣。起點越早，TWR 的歷史越完整；但從現在開始記，也比完全不記好。

**初次設定需要多久？** 如果你大致知道各帳戶的持倉和成本，從零設定到第一次看到有數據的儀表板，大概四十五分鐘到一個小時。設定完成後的日常維護成本很低：每次更新報價約一分鐘，每筆交易記入約三十秒，每個月花的時間通常不超過十分鐘。

**關於備份**：右上角有一個資料夾圖示，設定本機根目錄路徑之後，每次點「儲存」就會在那個資料夾產生一個以日期命名的 JSON 檔案。建議養成每次更新報價後順手存一次的習慣。換電腦時，從這個 JSON 重新載入，資料不會遺失。

## 今天就能做的三件事

**第一件**：去 GitHub 下載 Asset Dashboard 安裝檔，安裝後打開示範帳戶，瀏覽七個分頁，感受各功能的實際呈現。

**第二件**：用 [EP15 的方法](/articles/ep15-retirement-number) 算出你的財務自由目標金額，把這個數字輸入到退休規劃分頁，看看預測軌跡在哪個年份穿越目標線。

**第三件**：開始輸入你的第一筆持倉。不需要一次補完所有歷史，先從現在的持股開始，讓 TWR 計算從今天啟動。
